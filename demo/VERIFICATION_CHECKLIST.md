# Recording checklist

- [ ] Actual Lovable frontend URL works against the deployed FastAPI backend.
- [ ] Product answer displays at least two correct citations.
- [ ] Troubleshooting follows knowledge → troubleshooting → critic.
- [ ] Owned order returns verified amount.
- [ ] Security escalation produces a persisted ticket ID.
- [ ] Cross-account lookup is denied; another user's thread is inaccessible.
- [ ] Real Langfuse trace shows retrieval, embedding, tools and an actual model call when enabled.
- [ ] DeepEval run and saved trajectories are shown; explain a historical failure honestly.
- [ ] `/docs` executes an authenticated endpoint successfully.
- [ ] README setup and repository structure are shown, with secrets hidden.
- [ ] Restart and confirm threads and indexed sources persist.
- [ ] Final video lasts 7–10 minutes and is playable through the submitted link.

Do not tick an external service gate until it has actually been performed. Local screenshots are not proof of a Lovable deployment or Langfuse export.
