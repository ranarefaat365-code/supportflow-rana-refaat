المطلوب ببساطة

إنتِ بتعملي موظف دعم فني ذكي لشركة خيالية اسمها CloudBox. العميل يسأل، والنظام لازم يعرف: هل يجاوب من مستند؟ يشوف بيانات حسابه؟ يساعده يصلّح مشكلة؟ ولا يفتح تذكرة لمختص؟ لازم يوضح مصدر كلامه، وممنوع يطلع بيانات عميل لعميل تاني.

ده مش مجرد شات بوت أو Notebook. ده Backend وFrontend وقواعد بيانات واختبارات ومراقبة.

الجزء معناه بالمصري الموجود في التنفيذ
FastAPI الباب اللي الواجهة بتطلب منه كل حاجة التسع endpoints المطلوبة + عرض المحادثات والمراقبة
LangGraph بيحدد مين يستلم السؤال وبعده مين يراجع Orchestrator وخمس عقد متخصصة
RAG يدور جوه مستندات الشركة ويرجع دليل إدخال 13 مستند، metadata، Qdrant، فلاتر ومصادر
Account isolation كل واحد يشوف بياناته هو فقط هوية من token موثّق + فحص الحساب داخل استعلام قاعدة البيانات
PostgreSQL مكان تخزين المحادثات والتذاكر إعداد Docker جاهز؛ الاختبارات هنا استخدمت SQLite كبديل محلي
DeepEval يمتحن النظام على سيناريوهات 20 حالة أصلية + 12 إضافية، والجراف نفسه هو اللي اتشغّل
Langfuse تشوفي الطلب عدى على إيه وخد وقت قد إيه كود الربط وtraces محلية؛ الحساب الخارجي لسه محتاج مفاتيحك
Lovable الواجهة اللي العميل يتعامل معاها كود React كامل؛ إدخاله ونشره داخل Lovable لسه مطلوب
Demo فيديو يثبت الشغل قدام المراجع سكريبت إنجليزي وخطة 7–10 دقايق؛ الفيديو النهائي لسه يتسجل

أنا عملت إيه فعليًا؟

كتبت Backend جديد، وربطت الأدوات بالجراف، وعملت واجهة، واختبارات أمان، وتقييمات على تنفيذ حقيقي. ملف ZIP الأصلي كان فيه متطلبات وبيانات، مش مشروع محلول. الملف ده تنفيذ جديد مستقل.

مثال: لما تسألي عن ord_7001 وإنتِ داخلة بحساب user_1، النظام يقدر يرجع 29 دولار. لو طلبتي أوردر تابع لعميل تاني، بيمنعه حتى لو كتبتي إنك صاحبة الحساب. الكلام اللي في الرسالة مش إثبات هوية.

مثال تاني: لو قلتي إن حد دخل حسابك، بيختار مسار التصعيد، وبيعمل تذكرة برقم حقيقي محفوظ في قاعدة البيانات. ولو إنشاء التذكرة فشل، بيقول إنه فشل؛ مش بيطلع رقم وهمي.

مثال ثالث: لو سألتي عن عطل حالي، بينادي أداة الحالة. لو مفيش مصدر حالة متوصل، بيقول إن الحالة الحالية غير مؤكدة. مش بياخد حادثة قديمة من المستندات ويقول إن الخدمة واقعة دلوقتي.

الـAgents الخمسة بيعملوا إيه؟

  1. Knowledge: يجيب مقتطفات من المستندات، ومع كل مقتطف اسم المصدر وإصداره.
  2. Troubleshooting: يختار خطوات إصلاح مناسبة ويحافظ على ترتيبها والشروط المرتبطة بيها.
  3. Account tools: ينادي أدوات الحساب والأوردر والحالة، مع فحص صلاحياتك.
  4. Escalation: يفتح تذكرة للمشكلة اللي محتاجة مختص.
  5. Critic and response: يراجع إن المقتطف موجود فعلًا في الأدلة وإن المصادر موضحة قبل الرد.

الـOrchestrator فوقهم هو اللي بيختار المسار. هنا اختيار المسارات بقواعد واضحة، مش خمس موديلات مستقلة. وفي وضع اختياري موديل بيختار مقتطفات من الأدلة، لكن ما يقدرش يغير صلاحيات الحساب.

إيه لسه محتاج منك؟

المشروع المحلي شغال، لكن ما تسلّميهوش على إنه حقق كل المتطلبات الخارجية بالفعل.

  • شغّليه على جهازك وراجعي النتائج بنفسك.
  • كمّلي ربط ونشر الواجهة في Lovable. التعليمات في docs/LOVABLE_SETUP.md.
  • شغّلي إعداد PostgreSQL/Qdrant بالدّوكر وجرّبي إعادة التشغيل.
  • حطي مفاتيح Langfuse في .env محليًا، وشوفي trace حقيقي في الداشبورد وصوّريه.
  • لو مطلوب عرض model calls، فعّلي MODEL_MODE=llm بمفتاحك. ما تصوريش المفتاح.
  • جرّبي embeddings دلالية عبر API لو هتستخدمي وضع الإنتاج. الوضع الافتراضي المجاني بحث lexical، مش موديل فهم دلالي.
  • شغّلي تقييمات جودة الرد بالموديل الحَكَم لو متاح ميزانية API؛ النتائج الحالية اختبارات بنيوية، مش درجات faithfulness أو answer relevancy محسوبة بموديل.
  • ارفعي الكود على GitHub بعد التأكد إن .env وruntime مش مرفوعين.
  • سجّلي فيديو 7–10 دقايق من تشغيلك الفعلي. السكريبت في demo/ENGLISH_SCRIPT.md.

تشغّليه إزاي؟

  1. فكّي ZIP.
  2. افتحي Terminal داخل فولدر supportflow اللي فيه README.md.
  3. شغّلي ملفات Windows المرقّمة من نفس الفولدر؛ التفاصيل في QUICKSTART_WINDOWS.md.
  4. شغّلي 4_GET_TOKEN.cmd وخدي التوكن للاستخدام الخاص. ده تصريح تجربة لحساب وهمي، مش API key.
  5. شغّلي الـBackend في terminal والـFrontend في terminal تاني.
  6. افتحي http://127.0.0.1:5173، الصقي التوكن، وابدئي التجربة.

ما تحطيش API keys في الشات أو في الكود. .env.example قالب آمن؛ .env ملفك الخاص وممنوع يترفع.

تقولي للمراجع إيه بصدق؟

اشرحي اللي شغّلتيه فعلًا. ما تقوليش إن Langfuse أو Lovable أو تقييمات الموديل مكتملة قبل ما تجربيها. تقرير الاختبارات جوه artifacts بيفرق بين اللي اتنفذ واللي لسه إعداد أو كود محتاج تشغيل خارجي.
